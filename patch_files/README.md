# 4KING SOBAD - Auto Mod Patch Folder

นำไฟล์หรือโฟลเดอร์ที่คุณต้องการอัปเดตใส่ไว้ในโฟลเดอร์นี้ได้เลย:
- `SAMP/custom.ide`
- `texdb/samp.img`
- ฯลฯ

เมื่อ Commit ขึ้น GitHub ระบบ GitHub Actions จะรวมไฟล์เป็น `patch.zip` ให้อัตโนมัติ และอัปเดตเวอร์ชันใน `security.json` ให้ผู้เล่นทุกคนในมือถือดาวน์โหลดทันที!
